# 🧮 Calculadora em Python (POO)

Este projeto é uma **calculadora desenvolvida em Python**, utilizando os conceitos de **Programação Orientada a Objetos (POO)**.  
A aplicação funciona via terminal (console) e permite realizar operações matemáticas básicas de forma simples e segura.

---

## 🚀 Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Tratamento de divisão por zero
- Validação de entradas do usuário
- Menu interativo em loop

---

## 🛠️ Tecnologias Utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Estruturas de controle (`if / elif / else`)
- Tratamento de exceções (`try / except`)

---

## 📂 Estrutura do Projeto

- **Calculadora**: classe responsável pelas operações matemáticas  
- **menu()**: função responsável pela interface com o usuário  
- **main()**: função principal que controla o fluxo do programa  

Essa separação facilita a leitura, manutenção e evolução do código.
